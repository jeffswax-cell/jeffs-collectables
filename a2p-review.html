This page is provided for Twilio and The Campaign Registry (TCR) reviewers. It documents the complete SMS opt-in experience on our website with screenshots of each step.

Opt-in summary

SMS is optional and not a condition of purchase. Users may contact us by email instead. We support two web-based opt-in paths and no other opt-in methods (no keyword opt-in, no paper forms, no verbal opt-in).

Path 1: Homepage item card → "Enquire" button → modal → check unchecked consent box → "Send Enquiry via SMS"
Path 2: Direct navigation to /sms-consent → form → check unchecked consent box → "Send Enquiry via SMS"

After submission, the user's native SMS app opens with a pre-filled message to initiate the inquiry thread.

1. Homepage with item cards

The homepage displays available digital collectible items. Each item card has an "Enquire" button that opens the consent modal (shown next).

2. Enquire modal — consent unchecked, Send disabled

Clicking "Enquire" on any item opens this modal. The user enters their phone number, then must check the consent checkbox. The "Send Enquiry via SMS" button is disabled until the checkbox is checked and a valid phone number is entered. The consent checkbox starts unchecked (active consent required).

Checkbox disclosure text:

If you choose SMS, I agree to receive SMS messages from Jeff's Digital Collectibles LLC about this item enquiry. Msg frequency varies. Msg & Data rates may apply. Reply STOP to opt out, HELP for help. See Terms, Privacy Policy, and SMS Consent Policy. Consent is not a condition of purchase.

3. Enquire modal — consent checked, Send enabled

Once the user checks the consent box and enters a valid phone number, the "Send Enquiry via SMS" button becomes active. Clicking it opens the user's native SMS app pre-filled with a message addressed to Jeff initiating the inquiry thread.

4. Dedicated SMS Consent page

Live at: https://jeff.adscommandcenter.io/sms-consent

A standalone opt-in page also linked from the site header and footer. It contains the same enquiry form plus full program disclosures: Program Description, How to Opt In, Message Frequency, Message and Data Rates, How to Opt Out, Help, Supported Carriers, Privacy, and Terms.

5. Privacy Policy — SMS / Mobile Number Privacy section

Live at: https://jeff.adscommandcenter.io/privacy

Section 3 of the Privacy Policy explicitly states that mobile numbers and SMS consent information are not shared with third parties or affiliates for marketing or promotional purposes, and includes message frequency and message-and-data-rates disclosures.
